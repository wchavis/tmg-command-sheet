# TMG Command Sheet

An unofficial, fan-made play aid for the **StarCraft Tabletop Miniatures Game**.

Build an army from your Command Center roster, then play from one screen:

- abilities and weapons sorted by phase (Movement, Assault, Combat, Scoring, Always on)
- health tracking that drops model counts as units take damage
- tactical cards you can exhaust for their ability or spend for BM, with a BM pool
- a two-pane layout on foldables and tablets, single column on phones
- share any army as a link; works offline once installed

**Use it:** open the site in Chrome or Samsung Internet and choose *Install app* / *Add to Home screen*.
